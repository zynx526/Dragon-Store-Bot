# Dragon-Store-Bot

## Sobre
Bot Discord para loja Dragon Store com canais separados por categoria.

## Canais
- 📦 Contas
- 🍎 Frutas
- 🛒 Compras
- 🆘 Suporte

## Comandos administrativos
- `/painel contas`
- `/painel frutas`
- `/painel compras`
- `/painel suporte`
- `/produto adicionar`
- `/produto remover`
- `/produto editar`
- `/produto listar`
- `/estoque adicionar`
- `/estoque remover`
- `/estoque ver`
- `/pedido listar`
- `/pedido ver`
- `/pedido aprovar`
- `/pedido recusar`
- `/pedido entregar`

## Como instalar
1. Instale o Node.js 18+
2. Rode: `npm install`
3. Crie um arquivo `.env` baseado no `.env.example`
4. Preencha todas as variáveis
5. Rode: `npm start`

## Variáveis de ambiente
- `DISCORD_TOKEN` — token do bot
- `CLIENT_ID` — ID do cliente do bot
- `GUILD_ID` — servidor Discord
- `OWNER_ID` — usuário administrador principal
- `PIX_KEY` — chave Pix para pagamento manual (somente em ambiente local)

## Aviso
Nunca publique o token, chaves sensíveis ou credenciais em repositórios públicos.
